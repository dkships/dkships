### Hi, I'm David Kelly

I build open-source tools around Claude and MCP, and I ship consumer SaaS. Before this I spent 8 years building 9 products from zero to roughly 1M users at AppSumo Originals (TidyCal, SendFox, and others).

These days I build in public with Claude Code every day. I run free Claude Code workshops for non-technical founders.

#### What I'm building

- [pm-copilot](https://github.com/dkships/pm-copilot) is an MCP server that triangulates support tickets and feature requests so PMs can decide what to build next.
- [ship-sense](https://github.com/dkships/ship-sense) is an eval that scores frontier models on product judgment under uncertainty (what to refuse to build, when to hold a call).
- [llm-moods](https://github.com/dkships/llm-moods) is a live LLM sentiment dashboard (llmvibes.ai) that classifies posts with Claude Haiku.
- [substack-publisher-mcp](https://github.com/dkships/substack-publisher-mcp) is the first MCP server on Substack's official Publisher API.
